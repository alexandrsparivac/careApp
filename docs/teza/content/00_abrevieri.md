# LISTA ABREVIERILOR ȘI DEFINIȚIILOR

@@deflist
API :: Application Programming Interface – interfață de programare a aplicațiilor
BaaS :: Backend as a Service – platformă care oferă, sub formă de serviciu, componentele de server ale unei aplicații (bază de date, autentificare, stocare)
CDN :: Content Delivery Network – rețea distribuită de servere care livrează fișierele statice ale unei aplicații web
CLI :: Command Line Interface – interfață în linie de comandă
CSS :: Cascading Style Sheets – limbaj de descriere a prezentării documentelor web
DFD :: Data Flow Diagram – diagramă a fluxurilor de date
ER :: Entity–Relationship – model entitate–relație al unei baze de date
FK / PK :: Foreign Key / Primary Key – cheie străină / cheie primară
HTML :: HyperText Markup Language – limbaj de marcare a documentelor web
HTTPS :: HyperText Transfer Protocol Secure – protocol de transfer securizat al documentelor web
i18n :: internaționalizare – adaptarea aplicației pentru mai multe limbi (18 litere între „i” și „n” în cuvântul englezesc *internationalization*)
JSON / JSONB :: JavaScript Object Notation – format textual de schimb de date; JSONB – varianta binară din PostgreSQL
JWT :: JSON Web Token – jeton semnat care confirmă identitatea utilizatorului autentificat
OMS :: Organizația Mondială a Sănătății
ONU :: Organizația Națiunilor Unite
REST :: Representational State Transfer – stil arhitectural pentru interfețele de programare web
RLS :: Row Level Security – securitate la nivel de rând, mecanism PostgreSQL care filtrează rândurile accesibile fiecărui utilizator
RPC :: Remote Procedure Call – apel de procedură la distanță (funcție a bazei de date apelată prin API)
SGBD :: sistem de gestiune a bazelor de date
SPA :: Single Page Application – aplicație web cu o singură pagină, în care navigarea are loc fără reîncărcarea documentului
SQL :: Structured Query Language – limbaj de interogare a bazelor de date relaționale
SUS :: System Usability Scale – chestionar standardizat de evaluare a utilizabilității
UE :: Uniunea Europeană
UI :: User Interface – interfața cu utilizatorul
UML :: Unified Modeling Language – limbaj unificat de modelare
WAL :: Write-Ahead Log – jurnalul de modificări al PostgreSQL, folosit pentru replicare și pentru difuzarea modificărilor în timp real
WCAG :: Web Content Accessibility Guidelines – ghid de accesibilitate a conținutului web
WSS :: WebSocket Secure – canal bidirecțional securizat între navigator și server
backend :: partea de server a unei aplicații
deploy :: publicarea unei versiuni a aplicației într-un mediu accesibil utilizatorilor
frontend :: partea de client a unei aplicații, executată în navigator
open-source :: software cu cod sursă deschis
toast :: mesaj scurt afișat temporar într-un colț al ecranului
trigger :: procedură a bazei de date executată automat la inserarea, modificarea sau ștergerea unui rând

@@BODYSTART
