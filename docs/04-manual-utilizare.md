# 4. Manual de utilizare

## 4.1 Primii pași (pentru toți)

1. Deschideți aplicația și alegeți limba din colțul dreapta sus (**RO / EN / RU**). Limba se poate schimba oricând din meniul lateral sau din *Profilul meu* și se memorează pe cont.
2. **Creează cont** → alegeți *Membru al familiei* sau *Îngrijitor*, completați numele, e-mailul și o parolă de minimum 8 caractere.
3. Până când administratorul vă adaugă într-o echipă de îngrijire, panoul principal afișează mesajul „Încă nu faceți parte dintr-o echipă". Este normal.
4. *(Recomandat)* **Notificări → Activează notificările pe desktop**, ca să primiți alertele și când aplicația este într-un tab în fundal.

## 4.2 Administrator

| Sarcină | Pași |
|---|---|
| Adăugarea unei persoane asistate | Persoane asistate → **Adaugă persoană** → completați datele (numele este obligatoriu) → Salvează |
| Formarea echipei | Persoana → *Prezentare* → Echipa de îngrijire → **Adaugă membru** → alegeți utilizatorul și relația (ex. „fiică", „îngrijitor de noapte") |
| Scoaterea din echipă | același card → **×** lângă nume |
| Schimbarea rolului | Administrare → coloana *Rol* (nu vă puteți schimba propriul rol) |
| Dezactivarea unui cont | Administrare → **Dezactivează** (accesul se pierde imediat; se poate reactiva) |
| Date demonstrative | Administrare → **Generează date demonstrative** |
| Ștergerea unei persoane | Administrare → secțiunea *Persoane asistate* → coș de gunoi (șterge definitiv toate datele ei) |

## 4.3 Îngrijitor

**Planificarea**
- *Planificare* → **Planifică activitate**, sau „+ Adaugă" direct pe o zi din săptămână, sau din fișa persoanei → *Plan zilnic*.
- Alegeți categoria, ora, durata și responsabilul. Pentru activități repetate alegeți *Zilnic*, *În zilele lucrătoare* sau *Săptămânal* și data de sfârșit — aplicația arată câte apariții va crea.
- La editarea unei activități recurente puteți bifa *Aplică modificările și aparițiilor viitoare*.

**Evidența**
- Pe panoul principal sau în plan, butonul **Gata** marchează rapid activitatea ca realizată.
- Apăsând pe activitate: **Marchează ca realizată**, **Nerealizată** sau **Anulează activitatea**, cu *Note despre realizare* (vizibile familiei). **Redeschide** anulează marcajul.
- Activitățile rămase nebifate la 2 ore după intervalul planificat devin automat „nerealizate", iar echipa este anunțată.
- Cu 30 de minute înainte de o activitate primiți un memento.

**Observații**
- Fișa persoanei → *Jurnal* → **Adaugă observație**: stare generală (5 fețe), durere 0–10, semne vitale, apetit, somn, note.
- Dacă o valoare este în afara limitelor, formularul avertizează înainte de salvare; la salvare, toată echipa primește o alertă.

## 4.4 Membru al familiei

- **Panoul principal** arată ziua de azi pe „arcul zilei": punct verde = realizat, punct închis = planificat, inel chihlimbar = întârziat, roșu = nerealizat; soarele = ora curentă. Apăsați pe un punct pentru detalii.
- **Fișa persoanei → Prezentare**: evoluția tensiunii, pulsului, temperaturii etc. pe 14 zile (banda verde = interval normal, punctele roșii = valori anormale).
- **Jurnal**: tot ce s-a făcut și s-a observat, pe zile; filtrul *Doar alerte* arată numai problemele.
- **Mesaje**: conversația comună cu îngrijitorii. Enter trimite, Shift+Enter trece la rând nou.
- Puteți adăuga **observații** (ex. după o vizită) și **evenimente** (ex. o programare la medic).
- Planul poate fi doar vizualizat, nu modificat.

## 4.5 Notificări — ce primește fiecare

| Situație | Primește |
|---|---|
| Mesaj nou | toată echipa, mai puțin expeditorul (grupate pe fir) |
| Alertă de sănătate | toată echipa, mai puțin autorul |
| Eveniment nou / important | toată echipa, mai puțin autorul |
| Activitate atribuită | îngrijitorul responsabil |
| Memento (30 min înainte) | responsabilul, sau toți îngrijitorii dacă nu există responsabil |
| Activitate realizată | membrii familiei |
| Activitate nerealizată | toată echipa |

Apăsarea pe o notificare deschide direct locul relevant (firul de mesaje, jurnalul, planul sau evenimentul).
